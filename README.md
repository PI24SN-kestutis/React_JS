# HTML ir CSS pradmenys – Šachmatai

Paprastas vieno puslapio statinis projektas, sukurtas demonstruoti semantinę HTML5 struktūrą ir pagrindinius CSS stilius.

## Funkcionalumas ir reikalavimai

- **Semantinė struktūra:** Panaudoti `header`, `nav`, `main`, `section` ir `footer` elementai.
- **Tipografija ir tarpai:** Teksto stiliai, pastraipos, sąrašas (`ul`/`li`) ir išorinė nuoroda.
- **Flexbox navigacija:** Meniu nuorodos išdėstytos horizontaliai naudojant CSS Flexbox.
- **CSS kintamieji:** Šrifto nustatymas per `:root` selektorių.
